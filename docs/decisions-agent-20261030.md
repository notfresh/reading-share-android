# AI 助手关键决策记录(2.4.0 ~ 2.4.5)

> 记「为什么这么定」,不记代码细节。代码细节看 `dev-docs/release.md` 对应版本。
> 反向查阅用:遇到"能不能改成 X"时,先看这里当时为什么没选 X。

## 零、地基决策(2.4.0)

架构与工具层怎么搭 —— 后面所有 agent 功能都建在这上面。

### A. 架构形态

| 决策 | 选择 | 为什么 | 放弃的方案 |
|---|---|---|---|
| 部署形态 | **Python 内核跑在 app 进程内**(Chaquopy) | 用户明确要求"不用 server";省掉服务端改造和多一跳网络 | 独立 server / MCP server |
| 内核来源 | **minimal-agent-v2 是唯一源头**,app 侧 `app/src/main/python/` 是同步产物 | 双向改动必然漂移;Chaquopy 只认 app 侧目录 | 两边各改各的 |
| 跨语言引用 | **拆两类**:`AgentBridgeHost`(Python 持有)+ `PythonAgentBridge`(持 PyObject) | Chaquopy 文档警告:两语言互相持有的环**两个 GC 都检测不到** → 内存泄漏 | 一个类兼任两边 |

### B. 工具层

| 决策 | 选择 | 为什么 | 放弃的方案 |
|---|---|---|---|
| schema 位置 | **单一来源在 Java**(`AgentToolRegistry`) | 工具直接对应 DAO 能力;同源 = 改 DAO 加字段不会漏改 schema | Python 侧手写 |
| schema 传递 | **启动时拉取 + `register_external` 注入** | 不手抄第二份;改一处即生效 | 两份手抄 |
| 写操作落库 | **走同一条路**:同一 DAO + `EventLogClient` + `LinkJson` | 与用户手动操作完全同源 → 跨端同步/审计/回放白送 | agent 另建写入通道 |

### C. 安全边界

| 决策 | 选择 | 为什么 | 放弃的方案 |
|---|---|---|---|
| 确认机制 | **复用 V2 已有的 `runner.guard`** | guard 返回字符串 = 拒绝且工具不执行、错误回灌模型;不新造机制 | Python 侧另写拦截 |
| 兜底 | **三重保险**:无确认门→拒绝;60 秒超时→按拒绝;拒绝原因回灌模型 | 宁可不做,也不替用户决定 | 超时默认放行 |

### D. 依赖与内核修复

| 决策 | 选择 | 为什么 | 放弃的方案 |
|---|---|---|---|
| openai SDK | **锁 1.30.0** + pydantic 1.10.13 + httpx 0.27.2 | ≥1.40 硬依赖 `jiter`(Rust),Chaquopy 无 Android wheel → 装不上;httpx 0.28 移除 proxies 会让 openai 1.30 TypeError | 追新版本(装不上) |
| Python 版本 | **3.11**(V2 原写 ≥3.13,已放宽) | 实测语法兼容;3.12+ 不提供 32 位 ABI | 3.13 |
| 内核 bug | **修 V2 `_success_result` 缺 `append(assistant)`** | 抓包实测:桌面端多轮上下文也只带用户提问、丢 agent 回答 —— `session_manager.py` 那句「已包含 assistant 回复」不成立。修在 V2 源头,**桌面端一并受益** | 在 Android 侧绕(治标) |
| 工具注册 | **`register_external` 改幂等**(同名替换而非再 append) | 注册表是模块级全局;不幂等第 3 轮 tools 里有 3 份同名 → openai 报 Duplicate function names | 每次 run 重建注册表 |

## 一、会话历史(2.4.4)

| 决策 | 选择 | 为什么 | 放弃的方案 |
|---|---|---|---|
| 存什么 | **LLM 原生消息流**(含 tool_calls / role=tool) | 切回历史要能**接着聊**,上下文必须完整 | 只存界面气泡 → 切回后 agent 失忆 |
| 界面气泡哪来 | 从消息流**推导**(`display_messages`) | 单一来源,不会两处不一致 | 另存一份 display 列表 → 双写、必分叉 |
| 落哪 | app 私有目录 JSON,一段会话一个文件 | 规模小(≤50 段),SQLite 是过度工程(YAGNI) | Room / 塞进 links 库 → 迁移成本高 |
| 写盘 | 原子写(`.tmp` + `os.replace`) | 写到一半被杀不会留坏文件 | 直接覆盖写 |
| 保留 | 最近 50 段,最老自动删 | 用户实际不会翻第 51 段 | 无限保留 → 目录长期膨胀 |
| 「新对话」 | **懒创建**:第一次发消息才建文件 | 点几次「新对话」不会积一堆 0 轮空会话 | 点了就建 → 列表被空会话淹没 |
| 切换语义 | **接着聊**(恢复完整上下文) | 用户要的是"回来继续",不是只读归档 | 只读历史 |
| 名字过滤 | 在 **Java 内存**里 contains | 全量 ≤50 条,一次拉完本地过滤,零 JNI 抖动 | 每次按键跨 JNI 问 Python |
| Fragment 重建 | `onStart` 时按 current_conversation_id 重贴气泡 | 从 WebView 返回/AI 助手页切回不"空掉" | 不管 → 用户以为历史丢了 |

## 二、自动起名(2.4.4)

| 决策 | 选择 | 为什么 |
|---|---|---|
| 触发条件 | `轮数 > 3` 且 `title_generated = false`,**同时**满足 | 前三轮信息才够总结;已起过名的不许再改 |
| 素材 | 只取**前 3 轮**问答 | 用户拍板;早期话题定义会话主题,后面容易跑题 |
| 次数 | **只跑一次**(起过名永不再改) | 名字频繁变动比名字不完美更烦 |
| 失败处理 | 保留「新对话」,**下一轮自动重试** | 这是对"只执行一次"的**有意偏差**:一次网络抖动不该让会话永远没名字;仍满足 `title_generated=false` 才会重试 |
| 长度 | ≤12 字,剥标点/引号 | 列表一行要放得下(ellipsize 前尽量完整) |
| 时机 | 回合结束后同步跑一次(多约 1s) | 不引入额外线程池/回调;用户看到回答之后再关心标题 |
| 默认名 | 「新对话」 | 用户拍板 |

## 三、新工具(2.4.5)

| 工具 | 确认? | 决策要点 |
|---|---|---|
| `list_links_by_date` | **不需要**(只读) | 口径 = **设备本地时区自然日** `[00:00, 次日 00:00)`;走现成 `idx_links_timestamp`,不做全表扫;默认 20 条、上限 50(防止把 LLM 上下文灌爆) |
| `open_link` | **不需要**(用户明确要求放行) | 用 App **内置 WebView**(`WebViewActivity` 既有 `"url"` extra 契约),不跳外部浏览器;工具跑后台线程 → `FLAG_ACTIVITY_NEW_TASK` |
| 写工具(4 个) | **仍需确认** | 加/删标签、改备注、置顶 —— 会改库,确认门是唯一安全底线 |

边界原则:**只读 / 无副作用(打开页面)放行;改数据必须确认。**

## 四、前几轮顺带定下的(2.4.1 ~ 2.4.3)

| 决策 | 选择 | 为什么 |
|---|---|---|
| 布局主题属性 | 只用 M2(`colorPrimary/colorSurface/...`) | 项目主题是 `Theme.MaterialComponents`;M3 的 `*Container/*SurfaceVariant` 编译过、运行崩 |
| Python 启动 | `Python.start(new AndroidPlatform(ctx))` | `GenericPlatform` 是桌面 JVM 的,Android 上直接抛异常 |
| FAB 拖拽手势 | `onInterceptTouchEvent` 旁观 → 长按成立才拦截 | 子 FAB 自己在 DOWN 就消费事件,`OnTouchListener` 收不到后续 MOVE |
| 拖拽持久化 | 存绝对 `getX()/getY()`,onLayout 后重新夹紧 | 左手/右手模式改的是 layoutParams,不冲突 |
| AI 助手页 FAB 槽位1 | 收起 | 它压在输入行上,且本页没有"切换链接/主题"的语义 |

## 五、交付纪律(本轮踩出来的)

- 发给用户的 APK **文件名必须带版本**(`reading-share-2.4.5-v80-arm64.apk`),并给出期望字节数 —— 本次两次"安装失败"里有一次是 **404 页面被浏览器存成了 .apk**,不是包的问题。
- share 链接 **4 小时过期**;过期后手机请求是 404,表现像"下载很慢/装不上"。给链接时顺带说过期时间。
