# 网页内容提取技术实现

## 一、背景说明

### 1.1 功能概述

在 `WebViewActivity` 中，用户可以通过菜单项"提取Web内容"功能，将当前网页的主要内容提取出来并保存到剪贴板。这个功能的核心是使用 **Jsoup** 库解析 HTML，智能提取文章标题和正文内容。

### 1.2 使用场景

- **文章阅读**：快速提取网页文章内容，方便离线阅读或分享
- **内容保存**：将网页内容保存到剪贴板，便于粘贴到其他应用
- **信息整理**：提取关键信息，去除广告和无关内容

### 1.3 技术选型

- **Jsoup**：Java HTML 解析库，提供类似 jQuery 的 CSS 选择器 API
- **优势**：
  - 简单易用的 API
  - 支持 CSS 选择器
  - 自动处理 HTML 编码
  - 支持模拟浏览器请求头

## 二、核心实现原理

### 2.1 整体流程

```
用户点击"提取Web内容"按钮
  ↓
获取当前 WebView 的 URL
  ↓
后台线程执行网络请求（避免阻塞 UI）
  ↓
使用 Jsoup 连接并获取 HTML 文档
  ↓
根据网站类型选择不同的提取策略
  ↓
提取标题和正文内容
  ↓
格式化输出文本
  ↓
写入系统剪贴板
  ↓
显示成功提示
```

### 2.2 关键技术点

#### 2.2.1 模拟浏览器请求

为了绕过一些网站的反爬虫机制，需要模拟真实浏览器的请求头：

```java
Document doc = Jsoup.connect(url)
    .userAgent(Config.UserAgent.CHROME_USER_AGENT)  // Chrome 浏览器标识
    .header("Accept", Config.Headers.ACCEPT)         // 接受的内容类型
    .header("Accept-Language", Config.Headers.ACCEPT_LANGUAGE)  // 语言偏好
    .header("Accept-Encoding", Config.Headers.ACCEPT_ENCODING) // 编码支持
    .header("Connection", Config.Headers.CONNECTION) // 连接方式
    .header("Cache-Control", Config.Headers.CACHE_CONTROL) // 缓存控制
    .timeout(Config.Network.WECHAT_CRAWL_TIMEOUT)    // 超时设置（10秒）
    .maxBodySize(Config.Misc.MAX_BODY_SIZE)           // 响应大小限制（0=无限制）
    .followRedirects(Config.Misc.FOLLOW_REDIRECTS)  // 允许重定向
    .get();
```

**关键配置说明：**
- **User-Agent**：模拟 Chrome 浏览器，避免被识别为爬虫
- **Accept 头**：声明支持的内容类型，让服务器返回 HTML
- **超时设置**：10秒超时，避免长时间等待
- **重定向**：自动跟随重定向，处理 URL 跳转

#### 2.2.2 网站特定提取策略

不同网站的结构不同，需要针对性地提取内容：

**掘金博客（juejin.cn）专用策略：**

```java
if (url.contains("juejin.cn")) {
    // 提取标题（使用 data-id 属性定位）
    String title = doc.select("h2[data-id], h3[data-id], h4[data-id], h5[data-id], h6[data-id]").text();
    
    // 提取文章主体内容（使用特定的 CSS 选择器）
    Elements contentElements = doc.select(
        "div.article-viewer.markdown-body.result p, " +
        "div.article-viewer.markdown-body.result h2, " +
        "div.article-viewer.markdown-body.result h3, " +
        "div.article-viewer.markdown-body.result h4, " +
        "div.article-viewer.markdown-body.result h5, " +
        "div.article-viewer.markdown-body.result h6, " +
        "div.article-viewer.markdown-body.result li"
    );
    
    // 格式化输出
    for (Element element : contentElements) {
        String text = element.text().trim();
        if (!text.isEmpty()) {
            if (element.tagName().startsWith("h")) {
                // 标题：前后加空行
                contentBuilder.append("\n").append(text).append("\n");
            } else if (element.tagName().equals("li")) {
                // 列表项：添加 "- " 前缀
                contentBuilder.append("- ").append(text).append("\n");
            } else {
                // 段落：直接添加
                contentBuilder.append(text).append("\n");
            }
        }
    }
}
```

**通用网站策略：**


### 2.3 CSS 选择器详解

Jsoup 使用 CSS 选择器定位 HTML 元素，常用语法：

| 选择器 | 说明 | 示例 |
|--------|------|------|
| `tag` | 标签选择器 | `p` 选择所有 `<p>` 标签 |
| `.class` | 类选择器 | `.article-viewer` 选择 class 为 article-viewer 的元素 |
| `#id` | ID 选择器 | `#activity-name` 选择 id 为 activity-name 的元素 |
| `[attr]` | 属性选择器 | `[data-id]` 选择有 data-id 属性的元素 |
| `selector1, selector2` | 多选择器 | `p, h2` 选择所有 p 和 h2 元素 |
| `selector1 selector2` | 后代选择器 | `div.article-viewer p` 选择 div.article-viewer 内的所有 p |

**实际应用示例：**

```java
// 掘金博客的标题选择器
doc.select("h2[data-id], h3[data-id], h4[data-id], h5[data-id], h6[data-id]")
// 解释：选择所有有 data-id 属性的 h2-h6 标签

// 掘金博客的内容选择器
doc.select("div.article-viewer.markdown-body.result p, " +
           "div.article-viewer.markdown-body.result h2, ...")
// 解释：选择 div.article-viewer.markdown-body.result 内的 p、h2 等元素
```

### 3.1 核心方法：`CrawlUtil.getArticleByUrl()`

**位置：** `app/src/main/java/person/notfresh/readingshare/util/CrawlUtil.java`

**完整代码：**

```java
public static String getArticleByUrl(String url) throws IOException {
    // 1. 使用 Jsoup 连接并获取页面
    Document doc = Jsoup.connect(url)
            .userAgent(Config.UserAgent.CHROME_USER_AGENT)
            .header("Accept", Config.Headers.ACCEPT)
            .header("Accept-Language", Config.Headers.ACCEPT_LANGUAGE)
            .header("Accept-Encoding", Config.Headers.ACCEPT_ENCODING)
            .header("Connection", Config.Headers.CONNECTION)
            .header("Cache-Control", Config.Headers.CACHE_CONTROL)
            .timeout(Config.Network.WECHAT_CRAWL_TIMEOUT)
            .maxBodySize(Config.Misc.MAX_BODY_SIZE)
            .followRedirects(Config.Misc.FOLLOW_REDIRECTS)
            .get();
    
    // 2. 提取文章内容
    StringBuilder contentBuilder = new StringBuilder();
    
    // 3. 根据网站类型选择提取策略
    if (url.contains("juejin.cn")) {
        // 掘金博客专用提取逻辑
        // ...（见上文）
    } else {
        // 通用网站提取逻辑
        // ...（见上文）
    }
    
    // 4. 处理空内容情况
    String webContent = contentBuilder.toString().trim();
    if (webContent.isEmpty()) {
        webContent = doc.title();  // 至少返回页面标题
    }
    
    return webContent;
}
```

### 3.2 UI 层调用：`WebViewActivity.onOptionsItemSelected()`

**位置：** `app/src/main/java/person/notfresh/readingshare/WebViewActivity.java`

**关键代码：**

```java
else if (item.getItemId() == R.id.action_extract_content) {
    String url = webView != null ? webView.getUrl() : "";
    if (url.equals("")) {
        Toast.makeText(this, "Url为空", Toast.LENGTH_SHORT).show();
        return true;
    }
    
    // 使用后台线程执行网络请求，避免 NetworkOnMainThreadException
    ExecutorService executor = Executors.newSingleThreadExecutor();
    Handler handler = new Handler(Looper.getMainLooper());
    
    executor.execute(() -> {
        try {
            // 在后台线程提取内容
            String content = CrawlUtil.getArticleByUrl(url);
            
            // 切换回主线程更新 UI
            handler.post(() -> {
                try {
                    // 将提取的内容写入剪贴板
                    ClipboardManager clipboard = (ClipboardManager) 
                        getSystemService(CLIPBOARD_SERVICE);
                    ClipData clip = ClipData.newPlainText("extracted_content", content);
                    clipboard.setPrimaryClip(clip);
                    
                    Toast.makeText(this, "提取Web内容完成，已经写入剪切板", 
                        Toast.LENGTH_SHORT).show();
                } catch (Exception e) {
                    Toast.makeText(this, "提取失败", Toast.LENGTH_SHORT).show();
                }
            });
        } catch (Exception e) {
            handler.post(() -> {
                Toast.makeText(this, "提取失败", Toast.LENGTH_SHORT).show();
            });
        }
    });
    
    return true;
}
```

**关键点：**
1. **后台线程执行**：网络请求必须在后台线程执行，避免 `NetworkOnMainThreadException`
2. **主线程更新 UI**：使用 `Handler.post()` 切换回主线程更新 UI
3. **异常处理**：捕获所有异常，避免应用崩溃

## 四、技术要点总结

### 4.1 为什么使用 Jsoup？

| 方案 | 优点 | 缺点 |
|------|------|------|
| **Jsoup** | 简单易用、CSS 选择器、自动编码处理 | 需要额外依赖 |
| **正则表达式** | 无依赖 | 难以处理复杂 HTML、容易出错 |
| **XML 解析器** | 标准库 | 无法处理不规范 HTML |
| **WebView + JavaScript** | 可以执行 JS | 性能开销大、复杂 |

**选择 Jsoup 的原因：**
- HTML 解析更可靠（能处理不规范 HTML）
- CSS 选择器语法直观易用
- 自动处理字符编码
- 支持模拟浏览器请求头

### 4.2 提取策略设计

**当前实现：**
- **特定网站策略**：针对掘金博客使用专门的选择器
- **通用策略**：其他网站使用通用的段落提取

**扩展建议：**
1. **可配置化**：将网站特定的选择器配置化，便于扩展
2. **智能识别**：使用机器学习或规则引擎自动识别文章区域
3. **内容清理**：去除广告、导航等无关内容

### 4.3 性能优化

**当前优化：**
- 后台线程执行，不阻塞 UI
- 10秒超时，避免长时间等待
- 过滤短文本（长度 <= 10），减少无关内容

**进一步优化建议：**
1. **缓存机制**：对已提取的内容进行缓存
2. **流式处理**：对于大页面，使用流式解析
3. **并发控制**：限制同时进行的提取任务数量

### 4.4 错误处理

**当前处理：**
- 捕获所有异常，显示友好提示
- 空内容时返回页面标题作为兜底

**改进建议：**
1. **详细错误日志**：记录具体错误信息，便于调试
2. **重试机制**：网络错误时自动重试
3. **降级策略**：提取失败时提供替代方案

## 六、常见问题

### 6.1 为什么提取不到内容？

**可能原因：**
1. **网站反爬虫**：网站检测到非浏览器请求，返回空内容
2. **动态加载**：内容通过 JavaScript 动态加载，Jsoup 无法获取
3. **选择器错误**：CSS 选择器不匹配当前网站结构
4. **网络超时**：网络请求超时，未获取到完整 HTML

**解决方案：**
- 检查请求头是否完整
- 使用浏览器开发者工具查看实际 HTML 结构
- 增加超时时间
- 考虑使用 WebView + JavaScript 方案

### 6.2 提取的内容包含广告？

**原因：** 通用策略只过滤了短文本，无法识别广告区域

**解决方案：**
- 使用更精确的 CSS 选择器
- 识别并排除常见的广告容器（如 `.ad`, `.advertisement`）
- 使用内容密度算法识别文章主体

### 6.3 性能问题？

**可能原因：**
- 页面过大，解析耗时
- 网络请求慢

**解决方案：**
- 设置合理的超时时间
- 限制响应大小
- 使用缓存机制
