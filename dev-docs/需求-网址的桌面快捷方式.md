# 需求描述
有 WebView 和列表，只需要：
在长按网址项时，右键增加一个调用创建快捷方式的方法；
给快捷方式设置一个带 URL 的 Intent；
在 Activity 中接收这个 URL 并加载网页。

权限判断：某些 ROM（如小米、华为）可能会屏蔽 INSTALL_SHORTCUT，可提示用户手动添加或使用无障碍服务，这个时候，使用最下面的备选技术方案实现。

目标 Activity 单独设计：新建一个 WebShortcutActivity 专门处理快捷方式跳转，避免干扰主界面逻辑。
优先持 API 26+，可以使用 ShortcutManager 创建 固定快捷方式（Pinned Shortcut），更现代、更安全：

🚀 建议用户体验设计：

长按收藏项 → 弹出菜单 → “添加到桌面”

添加成功后 Toast 提示：“已添加快捷方式”

图标可以用默认图标或抓取 favicon

优化

第1步.动态图标：可以下载网站 favicon 作为快捷方式图标（需网络权限和异步下载）。
第2步.自定义图标：允许用户设计一张图片作为图标。


备选实现方式：
兼容方式（通过发送广播创建快捷方式）从后考虑。
假如非用支持更老的设备（很多厂商对 ShortcutManager 支持不一致），传统方式：通过 INSTALL_SHORTCUT 广播，但是整个以后再考虑。
