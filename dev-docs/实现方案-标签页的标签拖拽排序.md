#### 方案二：自定义拖拽手势（推荐用于 FlexboxLayout）

适用场景：保持现有 FlexboxLayout 结构

核心思路：
- 使用 `OnTouchListener` 监听触摸事件
- 手动处理拖拽逻辑和位置计算

实现要点：

1. 触摸事件处理
```java
tagItemView.setOnTouchListener(new View.OnTouchListener() {
    private float startX, startY;
    private boolean isDragging = false;
    
    @Override
    public boolean onTouch(View v, MotionEvent event) {
        switch (event.getAction()) {
            case MotionEvent.ACTION_DOWN:
                startX = event.getRawX();
                startY = event.getRawY();
                // 记录初始位置
                break;
                
            case MotionEvent.ACTION_MOVE:
                float deltaX = event.getRawX() - startX;
                float deltaY = event.getRawY() - startY;
                
                // 判断是否开始拖拽（移动距离超过阈值）
                if (!isDragging && (Math.abs(deltaX) > 10 || Math.abs(deltaY) > 10)) {
                    isDragging = true;
                    startDrag(v);
                }
                
                if (isDragging) {
                    // 更新拖拽视图位置
                    updateDragPosition(v, event.getRawX(), event.getRawY());
                    // 检测是否与其他标签交换位置
                    checkSwapPosition(v, event.getRawX(), event.getRawY());
                }
                break;
                
            case MotionEvent.ACTION_UP:
            case MotionEvent.ACTION_CANCEL:
                if (isDragging) {
                    endDrag(v);
                    isDragging = false;
                }
                break;
        }
        return true; // 消费事件
    }
});
```

2. 拖拽视觉反馈
```java

}
```

3. 位置交换逻辑
```java
private void checkSwapPosition(View draggedView, float x, float y) {
    // 1. 遍历所有子视图，找到当前触摸点下的视图
    for (int i = 0; i < tagsContainer.getChildCount(); i++) {
        View child = tagsContainer.getChildAt(i);
        if (child == draggedView) continue;
        
        // 2. 检查触摸点是否在子视图范围内
        int[] location = new int[2];
        child.getLocationOnScreen(location);
        Rect rect = new Rect(
            location[0], 
            location[1], 
            location[0] + child.getWidth(),
            location[1] + child.getHeight()
        );
        
        if (rect.contains((int)x, (int)y)) {
            // 3. 交换位置
            swapViews(draggedView, child);
            break;
        }
    }
}

private void swapViews(View view1, View view2) {
    int index1 = tagsContainer.indexOfChild(view1);
    int index2 = tagsContainer.indexOfChild(view2);
    
    // 移除两个视图
    tagsContainer.removeViewAt(index1);
    tagsContainer.removeViewAt(index2);
    
    // 重新插入（交换位置）
    if (index1 < index2) {
        tagsContainer.addView(view2, index1);
        tagsContainer.addView(view1, index2);
    } else {
        tagsContainer.addView(view1, index2);
        tagsContainer.addView(view2, index1);
    }
    
    // 保存新的排序
    saveTagOrder();
}
```

4. 保存排序
```java
private void saveTagOrder() {
    List<String> tagOrder = new ArrayList<>();
    for (int i = 0; i < tagsContainer.getChildCount(); i++) {
        View child = tagsContainer.getChildAt(i);
        String tagName = getTagNameFromView(child);
        if (!NO_TAG.equals(tagName)) { // 排除"无标签"
            tagOrder.add(tagName);
        }
    }
    // 保存到 SharedPreferences 或数据库
    persistTagOrder(tagOrder);
}
```

优点：
- 保持现有 FlexboxLayout 结构
- 灵活，可自定义交互
- 改动相对较小

缺点：
- 需要处理触摸事件和位置计算
- 需要处理边界情况
- 实现复杂度较高

#### 方案三：使用 DragShadowBuilder（Android 原生拖拽）

适用场景：系统级拖拽体验

核心思路：
- 使用 `View.startDrag()` API
- 系统处理拖拽视觉反馈

实现要点：

1. 启动拖拽
```java
tagItemView.setOnLongClickListener(v -> {
    // 创建拖拽数据
    ClipData dragData = ClipData.newPlainText("tag", tagName);
    
    // 创建拖拽阴影
    View.DragShadowBuilder shadowBuilder = new View.DragShadowBuilder(v);
    
    // 启动拖拽
    v.startDrag(dragData, shadowBuilder, v, 0);
    
    return true;
});
```

2. 监听拖拽事件
```java
tagsContainer.setOnDragListener(new View.OnDragListener() {
    @Override
    public boolean onDrag(View v, DragEvent event) {
        switch (event.getAction()) {
            case DragEvent.ACTION_DRAG_STARTED:
                // 拖拽开始
                return true;
                
            case DragEvent.ACTION_DRAG_ENTERED:
                // 进入容器
                return true;
                
            case DragEvent.ACTION_DRAG_LOCATION:
                // 拖拽位置更新
                // 检测是否需要交换位置
                checkSwapOnDrag(event.getX(), event.getY());
                return true;
                
            case DragEvent.ACTION_DROP:
                // 放下
                handleDrop(event);
                return true;
                
            case DragEvent.ACTION_DRAG_ENDED:
                // 拖拽结束
                return true;
        }
        return false;
    }
});
```

优点：
- 系统原生支持
- 视觉反馈统一
- 代码相对简洁

缺点：
- 需要长按启动（或自定义触发）
- 对 FlexboxLayout 的位置计算需要额外处理
- 某些设备上体验可能不一致
