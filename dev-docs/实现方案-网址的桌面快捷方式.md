# 桌面快捷方式实现方案

## 功能需求
在链接列表的长按菜单中，添加"添加到桌面"选项，点击后创建桌面快捷方式，点击快捷方式可直接打开对应的网页。

## 技术方案

### 1. 优先方案：ShortcutManager（API 26+）
- **使用方式**：`ShortcutManager.requestPinShortcut()` 创建固定快捷方式
- **构建工具**：使用 `ShortcutInfoCompat`（androidx 库，兼容性更好）
- **最低支持**：API 26（Android 8.0），不兼容更低版本
- **权限处理**：如果用户拒绝，显示提示信息

### 2. 快捷方式ID生成
- **生成方式**：使用 URL 的 hash 值作为唯一 ID
- **目的**：确保每个链接的快捷方式唯一，避免重复

### 3. WebShortcutActivity 设计
- **功能**：专门处理快捷方式跳转的 Activity
- **接收方式**：
  - 优先从 Intent extra 中获取 URL（`getStringExtra("url")`）
  - 如果没有，从 Intent data URI 中提取 URL
- **跳转逻辑**：提取 URL 后，启动 `WebViewActivity` 打开网页
- **生命周期**：打开 WebViewActivity 后立即 finish 自身

### 4. 用户体验流程
1. 用户长按链接项 → 弹出菜单
2. 选择"添加到桌面" → 调用 `ShortcutManager.requestPinShortcut()`
3. 系统显示原生确认对话框（系统UI）
4. 用户确认后 → 快捷方式创建成功
5. 显示 Toast："已添加快捷方式"

### 5. 图标和名称
- **图标**：暂使用应用默认图标（`R.mipmap.ic_launcher`）
- **名称**：使用链接标题（`LinkItem.getTitle()`）

## 实现清单

### 需要创建的文件
1. ✅ `WebShortcutActivity.java` - 处理快捷方式跳转
2. ✅ `ShortcutUtil.java` - 快捷方式创建工具类

### 需要修改的文件
1. ✅ `LinksAdapter.java` - 在长按菜单中添加"添加到桌面"选项
2. ✅ `AndroidManifest.xml` - 注册 WebShortcutActivity

### 实现细节

#### ShortcutUtil.java
- 方法：`createShortcut(Context context, String title, String url)`
- 使用 `ShortcutManagerCompat.requestPinShortcut()` 
- 快捷方式 ID：`"shortcut_" + url.hashCode()`
- 图标：`IconCompat.createWithResource(context, R.mipmap.ic_launcher)`
- Intent：启动 `WebShortcutActivity`，携带 URL 参数

#### WebShortcutActivity.java
- 在 `onCreate()` 中提取 URL
- 启动 `WebViewActivity` 并传递 URL
- 立即 finish 自身

#### LinksAdapter.java
- 菜单项 ID：7
- 菜单项文字："添加到桌面"
- 点击后调用 `ShortcutUtil.createShortcut()`
- 成功后显示 Toast

#### AndroidManifest.xml
- 注册 WebShortcutActivity
- 设置 Intent Filter（可选，用于支持直接通过 URL 打开）

## 注意事项

1. **权限**：ShortcutManager 在 Android 8.0+ 不需要特殊权限，系统会自动处理
2. **用户确认**：创建快捷方式时，系统会显示原生确认对话框，用户必须确认才能创建
3. **重复创建**：如果快捷方式已存在，系统会自动处理，不会重复创建
4. **ROM 兼容性**：某些厂商 ROM 可能对 ShortcutManager 支持不一致，如果遇到问题，后续考虑降级到 INSTALL_SHORTCUT 广播

## 最终实现总结

1. **优先使用 ShortcutManager（API 26+）**：与微信一致，在小米设备上也能正常工作
2. **降级方案**：ShortcutManager 失败时使用 INSTALL_SHORTCUT 广播
3. **WebShortcutActivity**：处理快捷方式跳转，打开对应的网页
4. **权限配置**：已在 AndroidManifest.xml 中声明所需权限

## 关键点

- 在小米设备上，需要在系统设置中开启“创建桌面快捷方式”权限
- 使用 ShortcutManager 时，系统会显示确认对话框（类似微信）
- 如果系统不支持，会自动降级到 INSTALL_SHORTCUT 广播方式
