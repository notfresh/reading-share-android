# 标题优化规则表

链接标题的「站点特化清洗规则」。每条规则 = 一个平台 + 一段可执行的改写逻辑。

规则按注册顺序匹配，**命中一条即返回**（当前只有一条）。

---

## 优化规则一：抖音 —— 切掉通用广告前缀

**作用**：抖音「复制链接」分享出来的文案，前面总是一段固定模板广告话术，
后面跟着真正的视频描述。用户看到这坨广告会很烦。

**规则**：从字符串**开头**一路切到 `看看` 两个字**之后**为止，剩下的部分原样保留。

**抖音分享文案的典型结构**：

```
1.00 复制打开抖音，看看【南巷旧人的作品】# 格斗魅力 # 暴力美学 # 硬帅天花板 https://v.douyin.com/lq35T16GunU/ :5pm xsE:/ 03/08 s@E.ho
└──────────── 从开头切到「看看」之后 ────────────┘└──────────── 剩下的原样保留 ────────────┘
```

**设计取舍（重要）**：

- **只切前缀，不做逐段清洗。** 不去拆 `【】`、不去拆 `#` 话题标签、不去砍尾部 `...`。
  剩下的部分原样保留 —— 用户的原话是「从开始到 看看两个字吧，把这些截掉就行」。
- **作者名、话题标签都保留。** 它们是有价值的内容，不是广告。
- **不写死「复制打开抖音」这个具体话术。** 锚点只用「看看」两个字 —— 抖音改文案模板时
  （比如换成「点击打开抖音，看看」），规则依然生效。
- **URL 之后的内容天然被排除。** 抖音尾巴有一串乱码（`:5pm xsE:/ 03/08 s@E.ho`），
  但 title 的提取范围是「URL 之前的文字」，所以不用管。

**已知边界**：

- 文案里如果**没有**「看看」两个字（另一种抖音模板：
  `长按复制此条消息，打开抖音搜索，观看视频！`），本规则不命中 → 标题保持原样。
  后续要覆盖那种模板，加「优化规则二」。
- 文案里「看看」出现在**别的位置**（比如正文里就有「看看这个」）→ 本规则会切错。
  当前判断条件是「链接的 host 是抖音域名」，所以只有抖音链接才会走这条规则，
  误伤面可控。

**抖音域名判定**：

- `v.douyin.com`（短链）
- `douyin.com` 主域及其子域
