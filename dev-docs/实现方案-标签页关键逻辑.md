## TagsFragment 标签管理逻辑解读

### 一、数据库结构（三张表）

#### 1. **`links` 表** - 存储链接/文章
- 字段：`_id`, `title`, `url`, `timestamp`, `source_app`, `is_pinned`, `click_count` 等

#### 2. **`tags` 表** - 存储标签
- 字段：
  - `_id` (主键)
  - `name` (标签名，UNIQUE 约束)

#### 3. **`link_tags` 表** - 关联表（多对多）
- 字段：
  - `link_id` (外键 → links._id)
  - `tag_id` (外键 → tags._id)
  - 复合主键：`(link_id, tag_id)`

关系：一个链接可以有多个标签，一个标签可以关联多个链接。

### 二、TagsFragment 的核心逻辑

#### 1. 标签显示与计数（`loadTags()` 方法，243-308行）

```java
// 后台线程加载标签数据
Map<String, Integer> tagsWithCount = linkDao.getTagsWithCount();
```

- 获取所有标签及其使用次数（通过 JOIN 查询 `link_tags` 统计）
- 显示逻辑：
  - 先显示“无标签”选项（统计无标签的链接数）
  - 再显示所有标签，每个标签显示使用次数
- UI 更新：使用 `item_tag_with_count` 布局，显示标签名和计数

#### 2. 标签选择与筛选（`updateTagSelection()` 方法，380-416行）

选择机制：
- 使用 `Set<View> selectedTags` 存储选中的标签视图
- 支持多选：可同时选中多个标签
- 点击已选中的标签会取消选择

筛选逻辑（`updateContentBySelectedTags()` 方法，705-780行）：
```java
// 1. 收集选中的标签名称
Set<String> selectedTagNames = new HashSet<>();
boolean hasNoTagFilter = false;  // 是否选中了"无标签"

// 2. 根据选择获取链接
if (selectedTags.isEmpty()) {
    links = linkDao.getAllLinks();  // 显示所有
} else {
    if (hasNoTagFilter) {
        links.addAll(linkDao.getLinksWithoutTags());  // 无标签的链接
    }
    if (!selectedTagNames.isEmpty()) {
        links.addAll(linkDao.getLinksByTags(selectedTagNames));  // 有这些标签的链接
    }
}
```

筛选规则：
- 未选择任何标签 → 显示所有链接
- 只选择“无标签” → 显示无标签的链接
- 选择普通标签 → 显示包含这些标签的链接（OR 关系）
- 同时选择“无标签”和普通标签 → 显示两者的并集

#### 3. 标签创建（`showAddTagDialog()` 方法，211-241行）

```java
// 1. 检查标签是否已存在
List<String> existingTags = linkDao.getAllTags();
if (existingTags.contains(tagName)) {
    // 标签已存在，显示提示
    return;
}

// 2. 添加新标签到数据库
long tagId = linkDao.addTag(tagName);
```

- 标签名唯一（数据库 UNIQUE 约束）
- 创建后立即刷新标签列表

#### 4. 标签删除（`confirmDeleteTag()` 方法，460-524行）

两种删除模式：

模式1：仅删除标签（`deleteTag()`）
```java
// 1. 查询标签ID
// 2. 删除 link_tags 表中的所有关联记录
// 3. 删除 tags 表中的标签记录
// 结果：链接保留，只是失去了这个标签
```

模式2：级联删除（`deleteTagWithLinks()`）
```java
// 1. 查询标签ID
// 2. 查找只有这一个标签的链接
// 3. 删除这些"孤立"的链接
// 4. 删除 link_tags 关联
// 5. 删除 tags 标签
// 结果：删除标签，同时删除只有这一个标签的链接
```

#### 5. 为链接添加标签（`addTagToLink()` 方法，870-953行）

```java
// 1. 检查标签是否存在
boolean isNewTag = !existingTags.contains(tag);

// 2. 如果是新标签，先创建
if (isNewTag) {
    long tagId = linkDao.addTag(tag);
    // 立即在UI中添加新标签视图
}

// 3. 为链接添加标签关联
linkDao.addTagToLink(item.getId(), tag);
```

内部实现（`LinkDao.addTagToLink()`）：
```java
public void addTagToLink(long linkId, String tagName) {
    long tagId = getOrCreateTag(tagName);  // 确保标签存在
    addTagToLink(linkId, tagId);  // 在 link_tags 表中插入关联
}
```

#### 6. 更新链接的标签（`updateLinkTags()` 方法，956-962行）

```java
public void updateLinkTags(LinkItem item) {
    // 1. 先删除该链接的所有标签关联
    database.delete(TABLE_LINK_TAGS, "link_id = ?", ...);
    
    // 2. 重新添加所有标签
    for (String tagName : item.getTags()) {
        long tagId = getOrCreateTag(tagName);
        addTagToLink(item.getId(), tagId);
    }
}
```

策略：先删除再重建，保证数据一致性。

#### 7. 标签高亮功能（`toggleTagHighlight()` 方法，1169-1184行）

- 使用 `SharedPreferences` 存储高亮标签集合
- 高亮标签显示为金色文字和加粗样式
- 高亮状态独立于选中状态

### 三、数据查询方法（LinkDao）

#### 1. `getTagsWithCount()` - 获取标签及使用次数
```sql
SELECT name FROM tags ORDER BY _id
-- 对每个标签，统计 link_tags 表中的关联数量
SELECT COUNT(lt.link_id) FROM tags t, link_tags lt 
WHERE t._id = lt.tag_id AND name = ?
```

#### 2. `getLinksByTag(String tag)` - 根据单个标签查询
```sql
SELECT DISTINCT l.* FROM links l
JOIN link_tags lt ON l._id = lt.link_id
JOIN tags t ON lt.tag_id = t._id
WHERE t.name = ?
```

#### 3. `getLinksByTags(Set<String> tags)` - 根据多个标签查询（OR）
```sql
SELECT DISTINCT l.* FROM links l
JOIN link_tags lt ON l._id = lt.link_id
JOIN tags t ON lt.tag_id = t._id
WHERE t.name IN (?, ?, ...)
ORDER BY l.timestamp DESC
```

#### 4. `getLinksWithoutTags()` - 获取无标签的链接
```sql
SELECT * FROM links l
WHERE NOT EXISTS (
    SELECT 1 FROM link_tags lt 
    WHERE l._id = lt.link_id
)
```

#### 5. `getLinkTags(long linkId)` - 获取链接的所有标签
```sql
SELECT t.name FROM tags t
JOIN link_tags lt ON t._id = lt.tag_id
WHERE lt.link_id = ?
```

### 四、关键设计特点

1. 多对多关系：通过中间表 `link_tags` 实现
2. 懒创建：使用 `getOrCreateTag()`，标签在使用时自动创建
3. 级联删除：支持仅删除标签或同时删除孤立链接
4. 多选筛选：支持同时选择多个标签，使用 OR 逻辑
5. 状态持久化：使用 `SharedPreferences` 保存标签选择状态和高亮状态
6. 实时更新：标签计数实时计算，删除/添加后立即刷新 UI

### 五、数据流转示例

场景：用户为链接添加标签 "Android"

1. 用户操作 → `TagsFragment.addTagToLink(item, "Android")`
2. 检查标签是否存在 → `linkDao.getAllTags()`
3. 如果不存在，创建标签 → `linkDao.addTag("Android")` → 插入 `tags` 表
4. 建立关联 → `linkDao.addTagToLink(linkId, "Android")` → 插入 `link_tags` 表
5. UI 更新 → 刷新标签列表，更新计数显示

这是一个典型的多对多关系管理实现，通过中间表维护标签与链接的关联。
