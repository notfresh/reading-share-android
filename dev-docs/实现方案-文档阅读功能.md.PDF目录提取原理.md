# PDF目录提取原理

## 一、PDF文件格式基础

PDF（Portable Document Format）是一种结构化的文档格式，由多个对象组成。PDF文件的基本结构：

```
%PDF-1.4                    # PDF版本头
...                         # 对象定义
xref                        # 交叉引用表
trailer                     # 文件尾
%%EOF                       # 文件结束标记
```

## 二、PDF目录（Outlines/Bookmarks）存储位置

PDF的目录信息存储在 **Outlines对象** 中，通常位于PDF的Catalog（目录）对象中。

### 2.1 目录对象结构

PDF的目录对象通常如下所示：

```pdf
/Catalog <<
  /Type /Catalog
  /Outlines 12 0 R          # 指向Outlines对象
  /Pages 3 0 R
>>

12 0 obj                   # Outlines对象
<<
  /Type /Outlines
  /First 13 0 R            # 第一个书签
  /Last 15 0 R             # 最后一个书签
  /Count 3                 # 书签总数
>>
endobj

13 0 obj                   # 第一个书签项
<<
  /Title (第一章 介绍)
  /Dest [3 0 R /XYZ 0 792 0]
  /Parent 12 0 R
  /Next 14 0 R
  /First 16 0 R            # 如果有子书签
  /Last 17 0 R
  /Count 2
>>
endobj
```

### 2.2 书签对象字段说明

- **`/Title`**: 书签标题（字符串）
- **`/Dest`**: 目标页面和位置（数组）
  - 格式：`[页码对象 /XYZ x y zoom]` 或 `[页码对象 /Fit]`
  - 例如：`[3 0 R /XYZ 0 792 0]` 表示跳转到第3页
- **`/Parent`**: 父书签对象引用
- **`/Next`**: 下一个同级书签
- **`/First`**: 第一个子书签
- **`/Last`**: 最后一个子书签
- **`/Count`**: 子书签数量

## 三、提取原理

### 3.1 基本思路

1. **读取PDF文件**：将PDF文件读取为字节数组
2. **转换为文本**：使用ISO-8859-1编码转换为字符串（保留二进制兼容性）
3. **正则匹配**：使用正则表达式查找书签对象
4. **解析字段**：提取Title和Dest字段
5. **计算页码**：从Dest中解析出页码

### 3.2 提取流程

```
PDF文件
  ↓
读取字节数组
  ↓
转换为字符串（ISO-8859-1编码）
  ↓
正则匹配：查找 << ... /Title (...) /Dest [...] >>
  ↓
提取标题和Dest
  ↓
解析Dest获取页码
  ↓
清理和验证
  ↓
去重和排序
  ↓
返回目录项列表
```

### 3.3 关键正则表达式

**匹配书签对象：**
```java
Pattern.compile(
    "<<[^>]*?/Title\\s*\\(([^)]+)\\)[^>]*?/Dest\\s*\\[([^\\]]+)\\]",
    Pattern.CASE_INSENSITIVE | Pattern.DOTALL
)
```

解释：
- `<<[^>]*?` - 匹配对象开始标记 `<<` 和前面的内容
- `/Title\\s*\\(([^)]+)\\)` - 匹配 `/Title (标题)`，捕获标题内容
- `[^>]*?` - 非贪婪匹配中间内容
- `/Dest\\s*\\[([^\\]]+)\\]` - 匹配 `/Dest [...]`，捕获Dest内容

**解析页码：**
```java
// Dest格式可能是：
// [3 0 R /XYZ 0 792 0] -> 页码是3
// [3 /XYZ ...] -> 页码是3
// 3 0 R -> 页码是3（对象引用）
```

## 四、页码解析原理

### 4.1 Dest格式类型

PDF的Dest（目标）有多种格式：

1. **命名目标**：`/Dest (目标名称)`
2. **数组格式**：
   - `[页码对象 /XYZ x y zoom]` - 指定页面和坐标
   - `[页码对象 /Fit]` - 适合页面
   - `[页码对象 /FitH top]` - 水平适合
   - `[页码对象 /FitV left]` - 垂直适合

3. **对象引用**：`页码对象 0 R`，其中页码对象指向实际的页面对象

### 4.2 页码提取策略

我们的提取器使用多种策略：

1. **查找 `/XYZ` 或 `/Fit` 之前的数字**（最常见）
   ```java
   Pattern.compile("(\\d+)\\s+/XYZ|(\\d+)\\s+/Fit")
   ```

2. **查找第一个合理的数字**（1-9999范围内）
   ```java
   Pattern.compile("\\b(\\d{1,4})\\b")
   ```

3. **解析对象引用格式**（如 `3 0 R`）
   ```java
   Pattern.compile("^(\\d+)\\s+\\d+\\s+R")
   ```

### 4.3 页码转换

PDF中的页码通常是：
- **对象编号**：从1开始的页面对象编号
- **页面索引**：需要转换为0-based索引（Android PdfRenderer使用）

转换公式：`pageIndex = pageNumber - 1`

## 五、层级计算

### 5.1 层级关系

PDF书签可以形成树形结构：
```
根目录 (level 0)
  ├─ 第一章 (level 0)
  │   ├─ 1.1 节 (level 1)
  │   └─ 1.2 节 (level 1)
  └─ 第二章 (level 0)
      └─ 2.1 节 (level 1)
```

### 5.2 层级估算

由于完整解析Parent/First/Last关系比较复杂，我们使用简化方法：

1. 查找当前位置之前的 `/Parent` 标记数量
2. 每个 `/Parent` 表示一级嵌套
3. 限制最大层级为5级

```java
// 在书签位置前后1000字符范围内查找Parent标记
Pattern parentPattern = Pattern.compile("/Parent");
int parentCount = 0;
while (parentMatcher.find()) {
    parentCount++;
}
level = Math.min(parentCount, 5);
```

## 六、限制和注意事项

### 6.1 当前实现的限制

1. **简单解析**：使用正则表达式，不是完整的PDF解析器
2. **页码可能不准确**：某些复杂格式可能无法正确解析
3. **层级估算**：层级计算是估算值，可能不够精确
4. **编码问题**：某些PDF可能使用特殊编码，标题可能乱码

### 6.2 无法处理的情况

1. **加密的PDF**：无法读取内容
2. **流式压缩的PDF**：内容被压缩，需要解压
3. **使用命名目标的PDF**：Dest是名称而非直接页码
4. **没有内置目录的PDF**：无法提取

### 6.3 改进方向

如果需要更准确的提取，可以考虑：

1. **完整PDF解析器**：解析PDF对象树，准确获取页码
2. **支持命名目标**：查找Name Tree中的目标定义
3. **处理压缩**：支持FlateDecode等压缩格式
4. **更精确的层级**：完整解析Parent/First/Last关系

## 七、代码实现要点

### 7.1 文件读取

```java
// 使用ISO-8859-1编码，保留所有字节（包括二进制数据）
byte[] pdfBytes = readFileBytes(pdfFile);
String pdfContent = new String(pdfBytes, StandardCharsets.ISO_8859_1);
```

### 7.2 标题清理

PDF字符串中的转义字符：
- `\(` → `(`
- `\)` → `)`
- `\n` → 换行
- `\r` → 回车
- `\t` → 制表符
- `\\` → `\`

### 7.3 过滤无效项

过滤掉明显不是目录的标题：
- 元数据标题（metadata, info, xref等）
- 长度不合理的标题（< 1 或 > 200字符）

## 八、性能考虑

1. **文件大小**：大文件读取可能占用内存
2. **正则匹配**：复杂正则可能较慢
3. **优化建议**：
   - 限制提取数量（最多200个）
   - 可以异步执行提取
   - 缓存提取结果

## 九、总结

PDF目录提取的核心是：
1. **理解PDF格式**：知道目录存储在哪里
2. **正则匹配**：找到书签对象
3. **字段解析**：提取Title和Dest
4. **页码计算**：从Dest中提取页码
5. **数据清理**：去重、排序、验证

虽然这种方法不如完整的PDF解析器精确，但对于大多数常见的PDF文件已经足够使用。
